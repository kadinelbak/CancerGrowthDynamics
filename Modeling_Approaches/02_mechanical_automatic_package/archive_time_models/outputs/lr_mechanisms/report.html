Generated 2026-09-27 20:39. At 0.5% FBS, A2780cis rises quickly, holds for a few days and then dies off to near zero. The earlier low-resource candidates all settle at a positive level, so they cannot reach zero. This report fits 16 candidate mechanisms to each low-resource monoculture (30k sheet) and asks which describe the data and send the population to zero.

  • As in the New data fitting report, the A2780cis day-0 value (the nominal seeding count, 5× below day 1) is dropped and day 1 is treated as day 0.
  • r and K are always the Stage 1 logistic values; only the low-resource terms are fitted. Hidden states (resource R, by-product W, quiescent Q, damaged D) start at the values shown in the equations.
  • Each mechanism is fitted from several starting points. The bootstrap-optimal model uses the same rule as the Bootstrapping report: 200 residual block-bootstrap replicates, and a simpler model is preferred when it is no more than 3 BIC worse per removed parameter.
  • Reaches zero? means the fitted model has fewer than 1 cell by day 200. Plots run to day 30; the shaded region is extrapolation beyond the data.
