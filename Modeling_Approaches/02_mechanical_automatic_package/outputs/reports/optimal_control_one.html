Model Selection Before Optimal Control

Seven candidate families are fitted jointly to the same 42 normalized A2780Naive observations across all three doses. BIC is \(n\log(\mathrm{SSE}/n)+k\log n\): lower is better, and every fitted parameter across all doses contributes to \(k\). Models within 2 BIC units are treated as similarly supported; within that set, the simplest boundary-free model is carried forward. This prevents a negligible BIC advantage or a bound-limited parameter from deciding the control model.

Selected model: shared-growth delayed loss. This is the simplest boundary-free member of the ΔBIC ≤ 2 supported set and is the only model carried into validation, sensitivity analysis, and optimal control.

Interpretation

  • BIC selects the most supported candidate among those tested; it does not prove biological truth.
  • Model selection precedes every downstream calculation in this report.
  • Held-out error tests interpolation at 1.0 µM; it is not included in that validation refit.
  • Near-optimal ranges expose parameter instability rather than presenting one optimizer result as exact.
  • The schedule is an in vitro model hypothesis, not a clinical recommendation.
