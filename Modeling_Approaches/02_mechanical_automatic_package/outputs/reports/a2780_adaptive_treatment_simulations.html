Mechanistic Model Used For The Sandbox

The simulator uses a simplified teaching model based on the staged A2780 equations. Naive cells are \(N\); A2780cis is split into sensitive-like \(S\) and tolerant/resistant-like \(T\).

\[C=S+T\]

Each lineage feels an effective coculture load:

\[L_N=N+\alpha_{NC}C,\qquad L_C=C+\alpha_{CN}N\]

Treatment intensity \(u(t)\) ranges from 0 to 1 and scales kill pressure. The original reference schedule refreshes media/treatment every 2 days, so the default reference simulation uses a two-day refresh interval.

\[\frac{dN}{dt}=G_N(N,L_N)-u(t)k_NN\]
\[\frac{dS}{dt}=G_C(C,L_C)\frac{S}{C}-u(t)k_SS-q_{ST}u(t)S\]
\[\frac{dT}{dt}=\rho_TG_C(C,L_C)\frac{T}{C}-u(t)k_TT+q_{ST}u(t)S\]

The optional \(q_{ST}\) term is a stress-induced shift from cis sensitive-like to tolerant-like behavior. It is set to a small value in the script so schedules can reveal resistant selection pressure. It is hypothetical and should be fit or validated before scientific claims.
