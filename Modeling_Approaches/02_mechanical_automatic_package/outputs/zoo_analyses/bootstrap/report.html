Bootstrapping — compartment models

Generated 2026-10-06 16:15 from the model zoo run of 2026-10-06 19:34 by zoo_analyses.jl. Every model here is a compartment model with no time-based terms; the model analysed in each fit is the carried-forward optimal model (fewest free parameters within 3 BIC of the lowest). Buttons marked explain how to read the graph or column next to them.

Method. Each fit is resampled 200 times. The residuals of the most complex candidate are resampled in circular blocks of 3 days within each trajectory (day 0 kept as observed) and added back to its fit; every candidate is refitted to every replicate and the selection rule (fewest free parameters within 3 BIC of the lowest; shared cisplatin structure across lines; Stage 2a shared-vs-separate test) is replayed on each. This gives how often the optimal model is chosen, 95% parameter intervals and the band around the fit. For comparison the optimal model is also passed through GrowthParameterEstimation.bootstrap_joint_fit, which resamples residuals one by one within each trajectory, as the earlier linked-treatment reports did; it ignores day-to-day correlation, so its intervals are usually narrower.
