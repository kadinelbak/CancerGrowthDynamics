Three views of how the fitted models depend on their parameters:

  • Global sensitivity (Sobol indices): every parameter varied together, each drawn uniformly and independently across its marginal 95% block-bootstrap percentile interval, and the variance of an output split between parameters. This is the view that matters for optimal control: which uncertain parameters actually change the predicted outcome.
  • Local sensitivity: the index of GrowthParameterEstimation.parameter_sensitivity_analysis, each fitted parameter moved ±10% with the others held: \(SI = \max|\Delta \hat y| / \max(\hat y, 1) / 0.1\) over every observed trajectory. (The package function handles one-state models, so the same formula is applied here to the multi-state compartment models.)
  • Profile likelihood: each parameter fixed at 0.5× to 2× its estimate and the others refitted with run_joint_multistart (3 starts, the same residual weights as the fit), to see whether the data pin it down. The profile is \(d(\theta) = n\ln(SSE_w(\theta)/SSE_{w,min})\) and a value is inside the 95% range while \(d\) stays below the small-sample threshold \(n\ln(1 + F_{1,n-k;0.95}/(n-k))\) (3.94–5.40 for these fits, against 3.84 for large n); the range ends are interpolated between grid points. Estimates on a search bound are flagged and not profiled (3 estimate(s) sit at or near a search limit, 3 of them on it).
