Three views of how the fitted models depend on their parameters:

  • Global sensitivity (Sobol indices): every parameter varied together across its whole plausible range (its 95% bootstrap interval), and the variance of an output split between parameters. This is the view that matters for optimal control: which uncertain parameters actually change the predicted outcome.
  • Local sensitivity: the index of GrowthParameterEstimation.parameter_sensitivity_analysis, each fitted parameter moved ±10% with the others held: \(SI = \max|\Delta \hat y| / \max(\hat y, 1) / 0.1\) over every observed trajectory. (The package function handles one-state models, so the same formula is applied here to the multi-state compartment models.)
  • Profile likelihood: each parameter fixed at 0.5× to 2× its estimate and the others refitted with run_joint_multistart, to see whether the data pin it down; plus the bound check of profile_joint_fit_bounds (2 estimate(s) sit at a search limit).
