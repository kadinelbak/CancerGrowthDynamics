# Modeling Approaches

Top-level organization for modelling strategies.

- `01_mechanical_manual`: migrated manual mechanistic workflow (current baseline).
- `02_mechanical_automatic_package`: reserved for package-driven mechanistic automation.
- `03_automatic_neural_network`: reserved for neural network modelling.

The legacy repository path `Modelling Data Notebooks` is preserved as a compatibility symlink to `Modeling_Approaches/01_mechanical_manual` during migration.
