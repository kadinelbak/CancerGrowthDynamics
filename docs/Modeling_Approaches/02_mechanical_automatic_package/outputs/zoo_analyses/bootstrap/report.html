Bootstrapping — compartment models

Generated 2026-10-24 04:49 from the model zoo run of 2026-10-23 23:06 by zoo_analyses.jl. Every model here is a compartment model with no time-based terms; the model analysed in each fit is the carried-forward optimal model (fewest free parameters within 3 BIC of the lowest). Buttons marked explain how to read the graph or column next to them.

Method. Each fit is resampled 40 times. The standardised residuals (residual ÷ its weight scale) of the generating model are resampled in circular blocks of 3 days within each trajectory, rescaled and added back to its fit; every candidate is refitted to every replicate and the selection rule (fewest free parameters within 3 BIC of the lowest; shared cisplatin structure across lines; Stage 2a shared-vs-separate test) is replayed on each. This gives how often the optimal model is chosen, 95% parameter intervals and the band around the fit. For comparison the optimal model is also refitted to a within-trajectory bootstrap that resamples the standardised residuals one by one (the scheme of GrowthParameterEstimation.bootstrap_joint_fit, used by the earlier linked-treatment reports; it is run here with the same residual weights as the fits, because the package routine cannot resample weighted data); it ignores day-to-day correlation, so its intervals are usually narrower.
