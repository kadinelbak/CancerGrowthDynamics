Every model here is a compartment model with no time-based terms; the model analysed in each fit is the carried-forward optimal model (fewest free parameters within 3 BIC of the lowest). Buttons marked explain how to read the graph or column next to them.

Three kinds of validation, each refitting the carried model without the held-out data and then predicting it:

  • Held-out treated cocultures (Ce1). The same held-out set as the neural-network track. The Stage 3a model's crowding terms (\(K, \alpha_{NC}, \alpha_{CN}, d_N\)) are fitted to the untreated Ce0 cocultures only; cisplatin comes from the Stage 2b monoculture fits (\(\beta_N = 0.9669\), \(\beta_C = 0.3721\), with their delays and Hill slopes). The Ce1 cocultures (90 points) are then predicted without refitting.
  • Blocked validation with GrowthParameterEstimation.blocked_joint_validation, as in the earlier linked-treatment reports: each whole block of trajectories (one dose, one seeding ratio, one experimental run) is held out in turn, the model is refitted to the rest from 3 starts, and the held-out block is predicted.
  • Forecast. Each fit is refitted to the first 70% of days and predicts the remaining days.

Scores: RMSE in cells; nRMSE = RMSE / mean of the held-out data. The ratio held-out / in-sample compares with the full fit on the same points (1 = no loss from holding the data out).

Intermittent dosing (drug switched on or off at day 7)

The intermittent monoculture experiments (30k; 1 µM cisplatin for days 0–7 then removed, or added from day 7) were never used for fitting. The Stage 1 growth and Stage 2b drug models predict them with no refit (values are image areas, so one area-per-cell scale is profiled per trajectory). They also test the one untested assumption that matters for scheduling: after the drug is removed, the drug effect decays at the same rate k as it built up. A separate washout rate \(k_{off}\) is fitted and kept only if it passes the 3-BIC rule.
