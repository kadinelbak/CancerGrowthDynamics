Validation — compartment models

Generated 2026-10-24 04:49 from the model zoo run of 2026-10-23 23:06 by zoo_analyses.jl. Every model here is a compartment model with no time-based terms; the model analysed in each fit is the carried-forward optimal model (fewest free parameters within 3 BIC of the lowest). Buttons marked explain how to read the graph or column next to them.

Four kinds of validation, each predicting data that the fit being tested did not use:

  • Intermittent dosing, the untouched validation set: never used for fitting or model choice, predicted with no refit and no free scale from the nominal seeding.
  • Held-out treated cocultures (Ce1). The same held-out set as the neural-network track. The Stage 3a model's crowding terms (K, α_NC, α_CN, d_N, d_C) are fitted to the untreated Ce0 cocultures only, with the same residual weights as the carried fits; cisplatin comes from the Stage 2b monoculture fits (\(\beta_N = 0.8293\), \(\beta_C = 0.4848\), with their delays; each kill is scaled by its line's Norton–Simon growth factor). The Ce1 cocultures (84 points) are then predicted without refitting, from nominal seeding for every Ce1 series (the full fit had estimated the start of: Ce1 25S75R A2780, Ce1 50S50R A2780, Ce1 75S25R A2780).
  • Blocked validation (the leave-one-block-out scheme of GrowthParameterEstimation.blocked_joint_validation, as in the earlier linked-treatment reports, run here so the refits use the same residual weights as the carried fits): each whole block of trajectories (one dose, one seeding ratio, one experimental run) is held out in turn, the model is refitted to the rest from 3 starts, and the held-out block is predicted (from the nominal seeding where the full fit had estimated a start).
  • Forecast. Each fit is refitted to the first 70% of days (weighted) and predicts the remaining days.

Scores: RMSE in cells (raw, for interpretation); nRMSE = RMSE / mean of the held-out data; weighted RMSE = \(\sqrt{SSE_w/n}\), the residuals divided by their weight scales as in the fits (no units; it weighs small and large counts the way the fits do). The ratio held-out / in-sample (raw RMSE) compares with the full fit on the same points (1 = no loss from holding the data out). Every refit stops on an iteration cap (no time limit), so the scores are reproducible.

Washout hypothesis test

Separately, these data test the one untested assumption that matters for scheduling: after the drug is removed, the drug effect decays at the same rate \(k\) as it built up. A separate washout rate \(k_{off}\) of the first effect compartment while the dose is 0 is fitted to these data (one parameter, everything else fixed). BICs use the weighted SSE with the same residual weights as the fits; the extra rate is kept only if it lowers the BIC by more than 3.
