Model zoo fits — no time-based terms

Generated 2026-11-11 20:51. No model here uses time t directly. Every right-hand side depends only on the cell states and the two inputs, the cisplatin dose \(D\) and the low-resource level \(u_R\). Delays and accumulation come from extra states driven by those inputs, so any of these models can be driven by a changing dose schedule \(D(t)\) for optimal control. For a constant dose switched on at day 0, an effect compartment gives \(D(1-e^{-kt})\), the same curve as the archived time-delay term, but it stays correct when the dose changes.

  • Optimal model at each stage: among the candidates within 2 BIC of the lowest, the one with the fewest free parameters (lower BIC breaks ties). It is carried into the later stages, so a negative ΔBIC in a table marks a model that fits slightly better but needs more terms.
  • Stage 2b: both lines share one cisplatin mechanism structure with their own rates (the rule is applied to the joint BIC of the two lines). Stage 2a: a shared low-resource structure is tested against each line's own pick and used only if it is within 2 BIC with no more parameters.
  • At most 3 compartments per cell line (delay states plus damaged-cell states), so every model stays small enough for optimal control.
  • Bootstrap: every candidate is refitted to 200 residual block-bootstrap replicates (blocks of 3 days, generated from the carried model; starting values held at their fitted values) for 95% parameter intervals, the band around the fit, and how often the same rule picks each model (and how often it has the lowest BIC) when the data are resampled.
  • Starting values: day 0 is the nominal seeding (100 cells at 30k, split by the seeding ratio in cocultures), used as the initial condition, not as a data point. Where the first measured count is more than 3-fold above or below it, that series' starting value is estimated (one extra parameter per series, counted in the BIC).
  • Values carried over from earlier stages are held at their point estimates. The older time-based models are kept in the archive.
