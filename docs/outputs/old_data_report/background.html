Background and previous research

This section provides the scientific context for the legacy A2780 modeling program and points to the underlying evidence, equations, and future experimental work.

Scope. These are research analyses of A2780 and A2780cis population trajectories. They are intended to compare mechanistic hypotheses and guide experiments—not to make clinical treatment recommendations.

How the legacy analysis is organized

The staged workflow first characterizes untreated monoculture growth, then treatment timing in monoculture, then untreated sensitive–resistant coculture interactions, and finally treated coculture dynamics. This separates what can be learned from each experimental setting before carrying supported parameters forward.

Interpreting the comparisons

BIC ranks candidates only within a shared fitting objective and dataset. A lower BIC is a useful parsimony criterion, but it does not establish biological truth. The staged and reduced-workflow tabs make it possible to see which measurements support each inherited component and what information is lost when a stage is omitted.
