Archive: time-based model zoo

Frozen copies of the pages and code as they stood on 2026-09-29, before the switch to the autonomous model zoo.

Not for optimal control. Many of these models use time directly: a delay \(1-e^{-\lambda t}\), a switch-on day \(\tau\), a capacity that decays as \(e^{-\delta t}\), or an Erlang onset \(E_n(\lambda t)\). Such a term assumes the drug or the stress started at day 0 and never changes, so the model cannot follow a changing dose schedule. The current pages use the autonomous model zoo instead.
