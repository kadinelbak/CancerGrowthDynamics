The whole run

1 · Staged fitting

What flows forward

  • Only the carried model of a stage is passed on.
  • Growth law (Stage 1) is reused by every later stage.
  • Coculture stages refit only coupling terms (K, α, death, kill).
  • Stage 4 refits at most 2 parameters on top of 3a + 3b.

Selection rule

  • Fewest free parameters within 2 BIC of the lowest.
  • Ties: lower BIC.
  • Same rule replayed on each bootstrap replicate → “% chosen”.

Two-pass bootstrap new

  • Was: 200 replicates × all 132 candidates (26,400 refits).
  • Now: 40 for all; 160 more for every model that landed within 2 BIC of the best in any of the 40 (a superset of “selected at least once”, since the rule only ever picks inside that band), plus the lowest-BIC, carried and generating models.
  • Set by bootstrap_screen; 0 turns it off.

2 · Validation

Held-out sets

  • Leave one out: dose (2b), ratio (3a, 3b), run (3b).
  • Ce1: crowding fit on Ce0 only, drug from 2b. Not fully independent (used to pick weighting).
  • Intermittent dosing: never used anywhere, no refit.

Identifiability

  • Profile likelihood with small-sample F threshold.
  • “Pinned” = profile closes on both sides, not at a bound.
  • Weak: θ_C, β_C, d_C, α_CN, α_NC (at bound 5).

Hypothesis test

  • Washout: separate clearance k_off after drug removal.
  • Fitted to intermittent data, kept only by the 2-BIC rule.

3 · Optimal control

Why the cost changed new

  • Old look-ahead stopped at the run end, so late doses lowered the final count without delaying progression (scenario A).
  • New cost counts time above K/2 directly; final count is only a tie-break.

Run until progression new

  • A crossing alone does not stop the run.
  • Stops once above K/2 at 6 successive decisions (10 days), or once MPC has outlasted every baseline by 10 days; run lengths are caps.
  • Expected: A stops ~day 17–18, B runs to the cap.

How MPC is judged

  • Against no treatment and constant 1 µM, same stop rule.
  • Constant 1 µM is inside MPC’s own search, so it can only lose on bootstrap draws or noise.
  • A/B dose agreement: do both scenarios pick the same doses?

Unchanged from main: 2-day decisions, measured doses only for the data-supported MPC, scenarios A and B, three seeding ratios, toxicity proxy, robustness draws. The new design is committed on the branch (b3cf098) but has not been run yet; this map will need a refresh if its details change.
