1 · Staged fitting

1.1One cell line in one well: the general equation

States and inputs
  • \(X\): observed count of the line; \(V\): viable cells (\(V = X\) unless a damaged-cell action is on)
  • Inputs: cisplatin \(D(t)\) in µM, low resource \(u_R \in \{0, 0.955\}\) (10% vs 0.5% FBS)
  • Hidden states: delay chain \(A_j\), stress \(S_j\), damaged cells \(X_D\)
  • No equation uses \(t\) directly, so any dose schedule can drive it (what control needs)
Equation
$$\frac{dX}{dt} = \underbrace{r_{\text{eff}}\, V\, G\!\left(\frac{\text{crowd}}{K_{\text{eff}}}\right)}_{\text{growth}} \;-\; \underbrace{(d + \text{loss})\, V}_{\text{death}} \;-\; \underbrace{\text{out}}_{\text{damaged cells dying}}$$
  • Growth laws \(G(x)\): logistic \(1-x\); theta-logistic \(1-x^{\theta}\); Gompertz \(\ln(1/x)\)
  • crowd = \(X\) in monoculture; \(X + \alpha\cdot(\text{other line})\) in coculture (1.4)
  • Each mechanism module sets \(r_{\text{eff}}, K_{\text{eff}}\), adds to loss or out (1.2)
Code: zoo_models.jl line_rhs!, growth_termSolver: Tsit5, reltol = abstol = 1e-8, stops at every dose change

1.2The mechanism catalogue (kernel × action)

Kernel: input \(w\) → effect \(E\)
  • none: \(E = w\)
  • comp1: \(\dot A = k(w - A),\; E = A\)
  • chain2 / chain3: \(\dot A_1 = k(w - A_1),\; \dot A_j = k(A_{j-1} - A_j),\; E = A_n\)
  • second: \(\ddot A = \omega^2(w - A) - 2\zeta\omega\dot A,\; E = \max(A,0)\)
  • auc: \(\dot A = w,\; E = A\) (never cleared)
  • Strength multiplier: \(w \leftarrow \varepsilon w\) (ε = 1 unless refitted)
Action: what \(E\) does
  • loss: loss \(+\!= d_0 w + \beta E\)
  • hill: loss \(+\!= \beta\, E^h/(EC_{50}^h + E^h)\), EC50 = 1 µM (A2780), 8.34 µM (A2780cis)
  • damage: \(\dot X_D = \beta E V - \delta X_D\), out \(= \delta X_D\); transit: two stages at rate τ
  • capacity: \(K_{\text{eff}} = K/(1 + cE)\); fade: \(r_{\text{eff}} = r/(1+cE)\) plus \(d_0 w\)
  • rho / sep_r: rescaled \(r\), \(K\); resource: \(\dot R = -cERX/1000\), growth × R, loss \(\beta(1-R)\); toxin: \(\dot W = EX/1000 - \kappa W\), loss \(\gamma W\)
  • Limit: ≤ 3 compartments per line → drug zoo 20 candidates, low-resource zoo 29
Code: zoo_models.jl module_effect!, zoo_grid, DRUG_ZOO, LR_ZOO; bounds SLOT_BOUNDS, three starts per slot SLOT_STARTS

1.3Norton–Simon coupling (drug stages 2b, 3a, 4)

Rule
  • Drug kill is multiplied by the line’s own growth factor, so crowded, slowly cycling cells die less
  • No extra parameter; set per stage by kill_growth_coupled = true
Equation
$$\text{loss}_{\text{drug}} \leftarrow \text{loss}_{\text{drug}} \cdot \max\!\left(1 - \left(\tfrac{\text{crowd}}{K_{\text{eff}}}\right)^{\theta},\, 0\right) \qquad (\theta = 1 \text{ for logistic})$$
Code: zoo_models.jl growth_factor, ns_on

1.5Objective, weights, BIC

Residual weights
  • One pooled variance model for every series: spread grows like a power of the count
  • Floor of 50 cells = noise floor
  • Replaced per-point 3-well SDs (2 d.f. each, weights differed 3500-fold)
Equations
$$w_i = \max(y_i, 50)^{0.55},\qquad \text{SSE}_w = \sum_i \left(\frac{\hat y_i(\mathbf p) - y_i}{w_i}\right)^2$$ $$\text{BIC} = n \ln\!\left(\frac{\text{SSE}_w}{n}\right) + k \ln n \qquad (n \text{ points}, k \text{ free parameters})$$
  • Joint fits (several doses or wells) sum the weighted SSE over all series and fit one parameter vector
Code: zoo_data.jl point_scale; zoo_common.jl gpe_datasets; BIC in GrowthParameterEstimation src/fitting.jlConfig: stages.toml [selection] residual_weighting = "power", weight_power = 0.55

1.6Optimiser

Procedure per candidate
  • Several fixed starts (three per slot, listed in SLOT_STARTS / stages.toml starts), all box-bounded
  • From each start: BFGS (≤ 1500 iterations), then Nelder–Mead (≤ 2500) from the BFGS result; keep the lowest BIC
  • No wall-clock limits: every run stops on its iteration cap, so results are reproducible
  • Starting state at day 0 = nominal seeding, or estimated where flagged (0.1)
Bootstrap refits only
  • Work budget: ≤ 50 × the right-hand-side evaluations of one refit to the real data; over budget → that replicate’s BIC = ∞ and a row in time_limit_hits.csv
  • Single start from the original estimate
Code: bootstrap_tools.jl bs_fit; run_joint_fit in GrowthParameterEstimationConfig: bootstrap_work_factor = 50

1.7Selection rule

Per fit group
$$\mathcal S = \{j : \text{BIC}_j \le \min_i \text{BIC}_i + 2\},\qquad \text{carried} = \arg\min_{j \in \mathcal S}\,(k_j,\ \text{BIC}_j)$$
  • Fewest free parameters inside the 2-BIC band; lower BIC breaks ties. Was 3 BIC until 27 Oct.
Paired lines (Stages 2a, 2b)
  • shared (2b): one mechanism for both lines, chosen on \(\text{BIC}_N + \text{BIC}_C\) with \(k_N + k_C\)
  • ab (2a): A = each line picks separately; B = joint pick. Use B only if \(\text{BIC}_B \le \text{BIC}_A + 2\) and \(k_B \le k_A\)
  • Same rule replayed on every bootstrap replicate → selection frequency
Code: zoo_selection.jl rule_pick, joint_pick; RULE_BIC = 2.0

1.8Moving-block residual bootstrap two-pass is new

One replicate b
  • Generator = the carried model’s fit \(\hat y\) (not the most complex candidate)
  • Standardised residuals \(e_i / w_i\) within each trajectory
  • Draw a random start, take 3 consecutive days (circular), repeat until the series is full
  • \(y^{*}_i = \max(\hat y_i + w_i\, e^{*}_i,\ 0)\)
  • Refit every candidate to \(y^{*}\), replay the rule
Two passes and outputs
  • Pass 1: B = 40 replicates for all 132 candidates
  • Pass 2: 160 more for every candidate that was within 2 BIC of the lowest BIC in any of the 40 replicates (picked or not), plus each replicate’s lowest-BIC and rule pick, the carried model and the generating model; the rest are “screened out”. Every model selected at least once is inside that band, so the screen is looser than “selected at least once”. A model never in the band in 40 replicates would be picked in < 7% (95% bound)
  • 95% CI = 2.5–97.5 percentiles of the refitted parameters
  • Prediction band = percentiles of the refitted curves
  • % chosen = share of replicates whose replayed rule picks the carried model
Code: bootstrap_tools.jl bs_resample, BLOCK = 3; run_zoo_fits.jlConfig: bootstrap_generator = "selected", bootstrap_screen = 40, BOOT_B = 200Out: zoo_state.jls, zoo_parameters.csv

2.1Uncertainty cross-checks

iid within-trajectory bootstrap
  • Same as 1.8 but each standardised residual resampled one at a time (block = 1), carried model only
  • Usually narrower intervals: it ignores day-to-day correlation
Why blocks
$$\rho_1 = \text{corr}\!\left(\frac{e_t}{w_t}, \frac{e_{t+1}}{w_{t+1}}\right) \text{ per trajectory; } \rho_1 > 0 \Rightarrow \text{errors come in runs}$$
Code: zoo_analyses.jl iid_replicate, lag-1 autocorrelation

2.2Profile likelihood (“pinned” parameters)

Procedure per free parameter
  • Fix it at estimate × {0.5, 0.63, 0.79, 0.9, 1, 1.11, 1.26, 1.59, 2}; refit the others from 3 starts
  • Record the weighted SSE at each grid point
  • Walk outward from the minimum; interpolate the first crossing of the threshold on each side → 95% interval
  • Estimate within 0.1% of a search bound → “at bound”, not profiled
Threshold (small-sample likelihood ratio)
$$d(\theta) = n \ln\frac{\text{SSE}_w(\theta)}{\text{SSE}_w(\hat\theta)} \le n \ln\!\left(1 + \frac{F_{1,\,n-k;\,0.95}}{n-k}\right) \;\to\; 3.84 \text{ as } n \to \infty$$
  • Pinned = both crossings found and neither at a bound. Result: 16 of 23
Code: zoo_analyses.jl profile_threshold, profile_crossing, PROFILE_MULT

2.3Sensitivity: local index and Sobol

Local sensitivity index
$$SI_j = \frac{1}{0.1}\max_{t,\,\text{state}}\left|\frac{\hat y(p_j \pm 10\%) - \hat y(p)}{\hat y(p)}\right|$$
  • 1 = proportional response; ≈ 0 = prediction barely depends on \(p_j\)
Sobol (global)
  • Uniform draws inside each parameter’s 95% bootstrap interval, N = 16,384; Saltelli matrices A, B, \(A_B^{(i)}\)
  • First-order \(S_1\) and total \(S_T\) per output (cell counts at reported days)
  • 95% intervals from 200 bootstrap resamples of the rows
Code: zoo_analyses.jl local_si, sobol, GSA_N

2.4Held-out prediction

Schemes (validation.toml)
  • Leave one dose out: 2b, each line; leave one ratio out: 3a, 3b; leave one run out: 3b
  • Forecast: fit days ≤ 70% of last day, predict the rest (every group)
  • Ce1 held out: refit \(K, \alpha_{NC}, \alpha_{CN}, d_N, d_C\) on Ce0 only, drug from 2b, predict Ce1 from nominal seeding. Baseline: same crowding, no drug term
  • Intermittent dosing (on 0 / off 7, off 0 / on 7): 2b model, no refit, no free scale. The untouched set
Score
$$\text{NRMSE} = \frac{\sqrt{\tfrac{1}{m}\sum_{\text{held out}}(\hat y_i - y_i)^2}}{\overline{y}_{\text{group}}}$$
  • Held-out series start from the nominal seeding where the full fit had estimated a start
  • Results: median 0.43 over completed folds; Ce1 0.91
  • Ce1 informed the choice of weighting and drug model, so it is not fully independent (stated on the page)
  • Washout hypothesis: extra clearance \(k_{\text{off}}\) after removal, fitted to intermittent data, kept only by the 2-BIC rule

3.1Plant: the fitted model plus a host proxy

State and input
  • \(x = [N, C, A_{N,1..3}, A_{C,1..3}, (S_{C,1..3}), B, T]\)
  • \(u\) = cisplatin in the medium (µM), constant over each 2-day interval
  • Cells: Stage 3a equations (1.4) with \(D = u\); low-resource environment adds the Stage 4 modules
  • Integrated by fixed-step RK4, \(h = 0.05\) day (checked against Tsit5 in tests)
  • Start: 100 cells split by ratio; hidden states 0
Host proxy (de Pillis & Radunskaya 2001)
$$\dot B = s_B u - d_B B,\qquad \dot T = a_H(1 - e^{-B})(1 - T) - r_H T(1 - T)$$ $$s_B = d_B = r_H = 1,\ a_H = 0.1,\ B_{\text{tox}} = 0.25 \ (\text{healthy tissue} \ge 75\%)$$
  • In-vitro data carry no host; T stands in for the host cost of the same exposure

3.3The decision problem at every media change new cost

Horizon
  • Decision every \(\Delta = 2\) days
  • Look-ahead: 6 blocks of [1, 1, 2, 2, 4, 4] intervals = 28 days, one dose per block (move blocking)
  • Look-ahead is fixed; it no longer shrinks to the run end (lookahead_to_end = false)
  • Progression threshold \(B_{\text{prog}} = K/2\); smooth step width \(s = 0.02K\)
Cost
$$J(U) = \sum_{k=1}^{H} \ell_k + \varphi(x_{H+1}),\qquad x_{k+1} = F(x_k, u_k)$$ $$\ell_k = \underbrace{q_P \cdot \frac{1}{8}\sum_{m=1}^{8} \sigma\!\left(\frac{N + C - B_{\text{prog}}}{s}\right)\Big|_{t_k + m\Delta/8}}_{\text{fraction of the interval spent progressed}} + 10^{-3}\Big[\,q_B\tfrac{N+C}{K} + q_T\big(\tfrac{T}{B_{\text{tox}}}\big)^2 + r_u\big(\tfrac{u}{u_{\max}}\big)^2 + b_{\mu_T}\Big]$$ $$\varphi = 5\,\big[\ell\text{-state terms at } x_{H+1}\big] + 10^{-3}\, q_{RT}\, \frac{C_{H+1}}{K}$$
  • \(q_P = 10,\ q_B = 0.1,\ q_T = 1,\ r_u = 0.1,\ q_{RT} = 10\); \(\sigma\) = logistic
  • Summed over the look-ahead, the first term = \((q_P/\Delta)\) × days progressed, so minimising it maximises time to progression
  • Everything else is ×0.001: it only breaks ties between plans with the same time to progression (order: resistant cells, burden, dose, toxicity)
  • Burden barrier at \(B_{\text{cancer}} = K/2\) is off in the main run (same level as \(B_{\text{prog}}\)); shapes relaxed-log, quadratic, hard stay in the sweep
  • Was: \(\sigma\) evaluated only at the interval’s end, tie-breakers at full weight, shrinking look-ahead with a final-day cost
Code: control_mpc.jl step_progressed, interval_cost, plan_cost, objective_weightsConfig: [progression] substeps = 8, tiebreak_scale = 0.001; [cancer] barrier = "none"

3.4Solving it

Data-supported MPC (the main result)
  • \(u_k \in \{0, 0.62, 1, 1.47\}\) µM, so \(4^6 = 4096\) plans per decision
  • Exact depth-first search: expand children cheapest-first, share rollout prefixes, prune a branch once its partial cost exceeds the best (every term ≥ 0)
  • Warm start = last plan shifted by one interval
  • Constant 1 µM is one of the plans, so under its own model MPC cannot lose to it
Demonstration MPC (continuous \(0 \le u \le 3\) µM)
  • SQP by successive linearisation, ≤ 40 iterations, stop when the relative cost change < 1e-7
  • Each iteration: roll out; \(A_k, B_k\) by forward-mode AD; gradient by the adjoint \(\mu_k = \nabla\ell_k + A_k^\top\mu_{k+1}\); Gauss–Newton Hessian from \(S_{k+1} = A_k S_k + B_k e_k^\top\); box-constrained QP by projected accelerated gradient; line search on the true cost
  • Keeps the end-of-interval \(\sigma\) (its gradients need \(\ell(x_{k+1}, u_k)\))
Code: control_mpc.jl discrete_solve, sqp_solve, adjoint_gradient, gn_hessian, box_qp

3.5Closed loop, stop rules, outcomes new stop rules

Each step k
  • Observe N and C; robustness runs add log-normal noise, CV 10%: \(y = x\exp(\sigma z - \sigma^2/2)\), \(\sigma = \sqrt{\ln(1 + 0.1^2)}\), seed 20261006 + draw (paired across policies)
  • Rebuild hidden states by simulating the controller’s own model under the doses it applied
  • Solve 3.3–3.4, apply the first block’s dose for 2 days on the true plant
Stop computing when
  • Progression confirmed: \(N + C \ge B_{\text{prog}}\) at 6 successive decision times (10 days); the controller keeps re-planning through all six
  • Outlasted every comparator: MPC not progressed at (latest comparator progression + 10 days)
  • Comparators always run the whole length; run lengths 14 / 30 / 60 / 120 days are now caps
  • After a stop the rest follows the last plan and is not read for time to progression
Reported per policy
$$\text{TTP} = \text{start of the first spell with } N + C \ge B_{\text{prog}} \text{ lasting} \ge 10 \text{ days (or to the end)}$$
  • First day at threshold; days progressed; N and C on the progression day (replaces counts on an arbitrary last day); stop day and reason
  • Comparators under the same rule: no treatment; constant 1 µM; max dose 1.47; periodic; threshold adaptive (dose 1 µM on at \(N+C \ge 0.5 B_{\text{cancer}}\), off at \(\le 0.25 B_{\text{cancer}}\))
  • Robustness: every fixed schedule replayed on 200 bootstrap parameter draws; closed-loop MPC on the first 40 draws, every policy on the same draws and noise
Code: control_mpc.jl closed_loop, stop_now, time_to_progression, outcomes, threshold_policy; run_control.jlConfig: confirm_decisions = 6, settle_margin_days = 10, sustain_days = 10; [observation] [robustness]Out: outputs/control*/control_outcomes.csv (new columns N_at_progression, control_stopped_day, stop_reason)

3.6Dose + fasting run (two inputs)

Second input v
  • \(v \in \{0, 1\}\): fed (10% FBS) or a 48-h fast (0.5% FBS); \(u_R = 0.955\, v\)
  • At most 1 fasting interval in a row, then ≥ 1 fed interval; fasting cost \(r_v v^2\), \(r_v = 0.05\) (×0.001 as a tie-breaker)
  • Drug × low-resource strength interpolates between the two measured conditions: \(\varepsilon_X(u) = 1 + (\varepsilon_X^{S4} - 1)\min(u/1\,\mu M, 1)\); \(v = 0\) is exactly the normal plant, \((u, v) = (1, 1)\) exactly Stage 4
  • In-vitro effect at full strength: an upper bound for any patient fast
Host states P (protection), W (body weight)
$$\dot P = k_P(v - P),\qquad \dot T = a_H(1 - p_H P)(1 - e^{-B})(1 - T) - r_H T(1 - T)$$ $$\dot W = -k_W v + r_W(1 - W)(1 - v),\qquad k_W = 0.012,\ r_W = 0.15,\ W \ge 0.95$$
  • \(k_P = 1\), \(p_H = 0.5\) (up to 50% less healthy-tissue damage while protected; swept 0 / 0.5 / 0.8)
  • Weight cost \(q_W\big(\tfrac{1-W}{1-W_{\min}}\big)^2\) plus a relaxed barrier at \(W_{\min}\)
