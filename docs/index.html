Final Report

How To Use

Start with the Summary for the current answer at each stage, use the Presentation in lab meetings, and the Explorer to see what each parameter does. The Final Report holds every detailed analysis, including every candidate of the model zoo. Every current model is autonomous (no term uses time), so it can be driven by any dose schedule; the optimal-control report does exactly that. Summary, Presentation and Explorer refresh automatically whenever run_zoo_fits.jl finishes a full run.
