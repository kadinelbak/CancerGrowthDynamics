How To Use

For a lab meeting, start with the staged model comparison, use the delay-vs-compartment report to explain the competing mechanisms, and consult the research guide for evidence and citations. Use the simulator last to explore hypothetical schedules and initial tumor compositions.

The simulator is intentionally lightweight and runs entirely in the browser. It should be connected to fitted parameter exports before treating any schedule ranking as a scientific conclusion.
