New Data Report

This report reads every CSV and XLSX file in New Datasets, plots each source with a title that includes the file and sheet name, and shows a small sheet preview underneath. The labeling follows the experiment naming in your notes: LR means low resource, ce0 is untreated, ce1 is treated at IC50 (1 uM), and 1-1, 1-3, and 3-1 are co-culture sensitive:resistant ratios.

16 files
64 plotted sheets / tables
830 day-level observations
How to read the labels: the mono-culture files are the standalone CSV time courses, while the co-culture workbooks either split into untreated/treated paired sheets or contain many LR sheets for different ratios and cell types. Every chart is labeled with the exact file and sheet name it came from, and each sheet preview shows the first three rows when available.
